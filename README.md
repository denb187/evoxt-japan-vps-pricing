## 250GB 月流量到底是多少带宽

官网只标“每月流量”，没写端口带宽。第三方测评（2026 年 6 月）提到日本节点为 1Gbps 端口。这两件事要分开看：端口 1Gbps 是瞬时峰值，月流量是总额度，把额度摊到 30 天，实际能长期跑的平均速度是这样：

| 月流量 | 折合持续跑满的速度 |
| --- | --- |
| 250GB | 约 0.79 Mbps |
| 500GB | 约 1.58 Mbps |
| 1000GB | 约 3.16 Mbps |
| 2000GB | 约 6.3 Mbps |
| 3000GB | 约 9.5 Mbps |
| 5000GB | 约 15.8 Mbps |

这张表的意义在于：VM-0.5 和 VM-0.75 的 250GB，如果拿来看视频、做下载站、跑图床，端口再快也会在几天内把额度烧完。它适合的是小博客、API 后端、爬虫、监控节点这类流量零星的应用。图片多的独立站，至少从 VM-1.5 的 500GB 起步；做视频或大文件分发，这台机器不是合适的选择。

流量用超之后怎么处理，官网定价页没有写明。下单前开一张工单问清楚是限速、停机还是按量计费，比事后补救便宜。
